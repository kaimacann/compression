## Get started

The repository provides a C11 command-line tool for lossless byte compression, restoration, inspection, and search. It writes the project-specific `TCMP` v1 container; it does not claim compatibility with ZIP, gzip, or another standard archive format. Continue to [File handling](./guide/file-handling/) for container and output behaviour, or [Reference and troubleshooting](./guide/reference/) for commands and diagnostics.

:::warning[Data and security boundary]
The program does not encrypt files or process PDF structures or image pixels. `TCMP` is a learning-project format, not a security, backup, or general interchange format. Keep source files and use copies for experiments.
:::

## Run a complete round trip

The output paths must not already exist. A temporary directory keeps the example's outputs separate from the repository and avoids replacing files.

<Code language="bash">{`work_dir=$(mktemp -d)
./compression-demo compress samples/sample.txt "$work_dir/sample.tcmp"
./compression-demo decompress "$work_dir/sample.tcmp" "$work_dir/sample-restored.txt"
cmp samples/sample.txt "$work_dir/sample-restored.txt"
rm -r "$work_dir"`}</Code>

The `cmp` command prints nothing and returns success when the restored bytes are identical. For a small or incompressible input, `TCMP` may use a raw frame, which preserves the bytes but adds container overhead. The format and its limits are described in [File handling](./guide/file-handling/).

## Use the command-line modes

Pass paths as separate arguments. Quote paths that contain spaces. The process returns status `0` on success and a non-zero status when an argument, input, container, or output operation fails.

<Code language="text">{`compression-demo compress <input> <output.tcmp>
compression-demo decompress <input.tcmp> <output>
compression-demo inspect <input>
compression-demo search <input> <literal-text>
compression-demo --help`}</Code>

The same actions are available from `make run` or `./compression-demo`: compress, decompress, inspect, search, then exit. The `inspect` mode reports byte frequencies in sorted order. The `search` mode uses Knuth–Morris–Pratt and prints up to the first 20 zero-based match offsets.

### Examples

Use new destination paths for each run. The compression command leaves its source file unchanged.

<Code language="bash">{`./compression-demo compress "samples/sample.txt" "sample.tcmp"
./compression-demo decompress "sample.tcmp" "sample-restored.txt"
./compression-demo inspect "samples/sample.txt"
./compression-demo search "samples/sample.txt" "compression"`}</Code>

If either output already exists, the program refuses to replace it. Remove or rename the destination yourself before retrying.
