This documentation has two trees. Use the links below to open a tree. **Assessment** contains the assignment material and separate project proposals. **Compression** is the guide to installing, running, and understanding the repository demo.

| Tree                         | Use it for                                                                                                                |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| [Assessment](/assessment/)   | Assignment brief, submission requirements, report scaffold, and the separately labelled business and technical proposals. |
| [Compression](/compression/) | Install the toolchain, build and run the demo, understand file handling, and check supported behaviour.                   |

> The assessment brief is preserved as supplied. The authored proposals are not official assessment requirements. The Compression guide describes the current code and does not claim that stub operations implement a compression standard.
