## Submit the report

- **Due:** 1 November by 23:59
- **Available:** After 1 September at 06:00
- **Submit through:** Canvas, as a group
- **File:** One PDF
- **Length:** No more than 10 pages, plus one cover page, one table of contents, and appendices. Content over the limit will not be marked.

By submitting, the group confirms that the work is its own, the program has been tested in Ed, and the assignment description has been followed.

## Report rubric

The report contributes 15 of the assignment's 30 marks (15% of the subject grade).

## Objective, scope and program features

| Rating     | Points   | Description                                                                                                                  |
| ---------- | -------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Proficient | 3.75 Pts | Very clear and interesting objective. Scope is broad and challenging to achieve. Good discussion on features implemented.    |
| Competent  | 2 Pts    | Clear objective. Scope is sufficient for a group project. Reasonable discussion on features.                                 |
| Novice     | 1 Pts    | Objective of the program explained and the scope of the project is reasonably sufficient. Some features have been explained. |

| Rating     | Points   | Description                                                                                                                                                                                                                                                                                                                                               |
| ---------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
