## Assessment snapshot

- Due **1 November by 23:59**.
- Submit source files through Ed and one PDF report through Canvas.
- The report is limited to **10 pages**, plus one cover page, one table of contents, and appendices.
- The code and report each contribute 15 marks, for 30 marks total.
