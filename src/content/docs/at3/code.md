## Submit the source code

- **Due:** 1 November by 23:59
- **Submit through:** Ed, as a group
- **Required files:** One or more `.c` files, one or more `.h` files, and one makefile.
- **Optional input data:** Attach files needed to run the program; each must be smaller than 100 KB.

Do not upload zip files, executables, or file types other than those listed above. By submitting, the group confirms that the work is its own, the program has been tested in Ed, and the assignment description has been followed.

## Code rubric

The code contributes 15 of the assignment's 30 marks (15% of the subject grade).

### Coding style and modularity

| Rating | Points | Description |
| --- | ---: | --- |
| Proficient | 3.75 | All good habits listed in LAB01. A C library with protection against double inclusion has appropriate features broken into appropriate files. A makefile is provided. |
| Competent-Proficient | 3 | |
| Competent | 2 | Reasonably good habits. Effort to break the program into functions, or effort to implement a user-defined C library. |
| Novice-Competent | 1.5 | |
| Novice | 1 | Below-par effort. |

### Features and aesthetics

| Rating | Points | Description |
| --- | ---: | --- |
| Proficient | 3.75 | Features are useful and challenging to implement. The user interface is very intuitive. The program has multiple runtime modes that use command-line arguments. |
| Competent | 2 | Very useful features with a good, operable user interface. |
| Novice | 1 | Some reasonably functional features with an operable user interface. |

### Data compression/encryption

| Rating | Points | Description |
| --- | ---: | --- |
| Proficient | 3.75 | Implement reasonably complex compression/encryption algorithms and other advanced algorithms such as sorting and searching. Show advanced use of data structures such as stacks, queues, linked lists, and trees. |
| Competent | 2 | Reasonably complex compression/encryption algorithms have been implemented. Some effort to use advanced data structures. |
| Novice | 1 | Some effort to understand and use relevant compression/encryption concepts. |

### Bugs

| Rating | Points | Description |
| --- | ---: | --- |
| Proficient | 3.75 | No bugs are evident. Provide a debug mode (with preprocessing directives) that prints useful debug information to the terminal. Handle inputs outside the expected range and inputs of unexpected data types. |
| Competent | 2 | No bugs are evident. Handle inputs outside the expected range but of the expected data types. Provide a debug mode (with preprocessing directives) that prints useful debug information to the terminal. |
| Novice | 1 | Some bugs. |
