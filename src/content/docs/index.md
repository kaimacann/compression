## Assessment snapshot

- **Due date:** 1 November by 23:59.
- **Deliverables:** Submit source files through Ed and one PDF report through Canvas.
- **Page limit:** The report is limited to **10 pages**, plus one cover page, one table of contents, and appendices.
- **Weighting:** The code and report each contribute 15 marks, for 30 marks total.

## Project lifecycle

### Problem requirement

Find a real-world customer need involving compression and/or encryption.

### Problem analysis

Identify the inputs, outputs, and required resources. Break the task into functions and decide which features to add.

### Solution design

Choose algorithms and a program design—one file or a custom C library—and consider a user-friendly interface.

### Implement and test

Research simple encryption and/or compression algorithms. Implement one function at a time, test each function, debug, integrate, and complete the project report.

## Expected project checkpoints

### Week 08

Discuss the project description, select a problem, and outline functions and the report.

### Week 09

Before the lab, write function prototypes and block comments, produce a structure chart, and draft the report outline with its scope. During the lab, groups can ask tutors for feedback.

**Checkpoint 1:** Send the report outline and scope to the tutor. Submit one or more `.c` and `.h` files containing function prototypes, block comments, and each function's author. This checkpoint is mandatory. Submit the report outline through Canvas and source code through Ed.

### Week 10

Implement functions and algorithms, debug and integrate the code, then adjust scope and program design using tutor feedback.

### Week 11

Implement, debug, and integrate the code; document bugs and how they were fixed; and complete more report sections.

**Checkpoint 2:** Demonstrate a running, though not necessarily complete, program to the tutor in the lab. This checkpoint is mandatory.

### Week 12

Ensure the final program works and follows good coding style, then finalise the report.

**Checkpoint 3:** Demonstrate the complete program to the tutor in the lab. This checkpoint is mandatory.
